ThinkKira Web-Flasher

Firmware für das Elecrow ThinkNode M5 direkt aus dem Browser aufspielen. Die Firmware kommt immer aus dem neuesten GitHub-Release.

Version: wird geladen …

  1. Chrome oder Edge am PC verwenden (Web Serial).
  2. ThinkNode M5 per USB-C anschließen.
  3. Auf Installieren klicken und den Port wählen.
  4. Beim ersten Wechsel auf ThinkKira „Gerät löschen“ bestätigen.
Dein Browser kann das nicht. Bitte Chrome oder Edge am PC nutzen. Nur über HTTPS möglich.
